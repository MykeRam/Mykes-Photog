## Project Overview

This site is a personal portfolio that brings together my software engineering work and photography in one place. It is designed to introduce who I am, highlight the technical skills I am building, and present selected projects and visual work through a clean, interactive experience.

The site showcases:

- My background and interests as a developing software engineer and photographer
- A coding section featuring projects built throughout my learning journey
- A photography section that highlights selected image work in a dedicated gallery
- Motion, layout, and responsive design choices that reflect both technical and creative focus

This project uses the following tools and technologies:

- **React**  
  Used to build the user interface with reusable components and manage the overall frontend structure.

- **React DOM**  
  Connects the React application to the browser so the UI can render on the page.

- **Vite**  
  Serves as the development server and build tool. It provides fast local development, hot reloading, and optimized production builds.

- **@vitejs/plugin-react**  
  Adds React support to Vite so JSX and React-specific features work correctly during development and build.

- **Motion**  
  Used to create animations and transitions across the site, including interactive and visual effects for components.

- **Node.js**  
  Runs the project scripts and supports the local tooling used for development and image processing.

- **npm**  
  Manages project dependencies and runs scripts such as development, build, preview, and image conversion tasks.

- **Sharp**  
  Processes and optimizes images for the gallery by generating resized and compressed versions for better performance.

- **ImageMagick**  
  Acts as a fallback image-processing tool if Sharp is not available.

- **GitHub Actions**  
  Automates the build and deployment workflow whenever changes are pushed to the main branch.

- **GitHub Pages**  
  Hosts the finished static website after deployment.
